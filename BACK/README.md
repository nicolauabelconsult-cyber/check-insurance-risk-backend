# Check Insurance Risk API

## Descrição
Backend em FastAPI para validação e avaliação de risco de seguradoras, com endpoints de autenticação, verificação e relatórios Premium v3.

## Endpoints principais
- `/api/login` — Autenticação
- `/api/risk-check` — Avaliação de risco com PEP/sanções
- `/api/generate-report` — Geração de relatório Premium

## Executar localmente
```bash
pip install -r requirements.txt
bash run.sh
```

API disponível em http://localhost:8000/docs
